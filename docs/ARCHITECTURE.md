# Architecture

`game.tscn` owns the entrance/ready/running/game-over/eating state, static ground and instances the goat. The landscape draws the weather-driven sky and scrolling farm layers while running. The goat scene contains an SCML-generated visual built from SVG parts and a CharacterBody2D with separate rectangular head and body hitboxes. Walk, idle, run, duck, die and eating animations follow the game state; jumping uses the run animation because SCML has no jump animation. The unused standalone `blackgoat.svg` was removed; the SCML and its SVG parts are the goat's editable sources. The goat script applies gravity, variable-height jumps and a lowered head hitbox for ducking while Godot handles ground collision. The obstacle manager spawns and scrolls bush, puddle, hay bale and sock sprites with Area2D hitboxes; ground obstacles detect both shapes while the clothesline detects the head. Collisions stop the run. The hay bale triggers the transition and looping eating animations and disables gameplay input; its retry button reloads the scene. Other collisions use the death animation and allow retry with a bound jump key.


The `Interface` CanvasLayer in `game.tscn` uses `scripts/interface.gd` for translated menus, score display and pauseable settings. It registers Godot Translation resources for English, Dutch and German and stores interface preferences in `user://interface.cfg`; the high score remains in `user://highscore.cfg`. The settings panel uses `panel-wood-vertical.svg`, opens at the gear and can be dragged by its top edge or title. It supports independent touch-button layout and shared opacity. `scripts/touch_control.gd` draws the controls and edit handles and supplies jump/duck input; its visual opacity does not hide edit handles. The on-screen menu offers retry after every collision, including the eating state.

The keybind popup stages one optional keyboard key per action until confirmed. Explicit keys override the other action's defaults; removing them restores those defaults. Confirmed bindings are stored alongside interface preferences and rebuild the Godot InputMap on scene load. The same jump action controls gameplay, keyboard start and retry.

Settings popups share a centered wood-panel layout with a dark backdrop, generous inner margins and the supplied square wooden icon buttons. The wood-panel artwork has a thick decorative border: leave ample space inside it on every side so labels, fields and buttons stay clear of the border. The keybind popup uses 55-pixel panel content margins; the vertical settings panel uses 76 pixels horizontally, 65 at the top and 72 at the bottom. A green check confirms and a red cross cancels; the high-score confirmation uses the same layout and leaves the settings menu open. Use the supplied GUI artwork and the same pattern for future settings confirmations.

The viewport is 1440 × 720 with aspect-preserving canvas scaling. The Web preset uses Compatibility and disables threads.

`scenes/landscape.tscn` contains the sky/controller, `FarmScenery` and fog overlay behind gameplay, plus a precipitation overlay in front of the goat and obstacles. The controller forwards its scroll distance to `scripts/farm_scenery.gd`. FastNoiseLite supplies shared world-coordinate terrain samples; four parallax caches and a separate half-speed fence cache hold at most six chunks each. Each chunk uses an independent seeded RNG for decor, with no collision nodes. Fence chunks combine closed panels, normal/mirrored gates and single or paired open leaves; openings contain no connecting rails. A nonzero exported `landscape_seed` gives reproducible scenery; zero chooses a new seed on scene reload. The track is unchanged, background decor ends above it, and foreground decor begins below it. `tools/extract_environment.py` rebuilds the decor SVGs from the supplied grouped source artwork.

The `Weather` autoload requests Open-Meteo for the fixed coordinates on startup and every 15 minutes. It retains the last valid current conditions across scene reloads and network failures. The landscape gradually maps those conditions to sky, clouds, precipitation, fog and wind; they do not change gameplay.

The debug menu can enable autoplay. It sets obstacle elapsed time to 30 minutes, selects a random next kind, and supplies jump and duck controls to the goat while retaining normal physics, collisions and scoring. Each obstacle receives a slightly varied action distance; the controller uses shorter jump holds for bushes and puddles and longer ones for hay. A collision stops the run, and retry reloads the scene with autoplay off.
